ESP32·Firebase 연동 설정

GitHub Pages는 정적 웹사이트이므로 ESP32와 직접 통신하지 않고 Firebase Realtime Database를 중간 서버로 사용합니다.

반응시간 기준: ESP32에서 알람이 시작된 시각부터 사용자가 하드웨어 버튼을 누른 시각까지입니다. 초음파 센서는 수령이 아니라 약포지 배출 완료를 확인합니다.

Realtime Database URL을 입력하면 일정과 ESP32 상태를 동기화할 수 있습니다.
